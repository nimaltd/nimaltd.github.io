Libraries, engineered to drop in.

Lightweight, non-blocking C libraries for STM32. Those ready for lib-installer go into any project with one command, and the rest are moving over one by one.

Driver for SPI NOR flash, W25Qxx and compatible, on the STM32 HAL.

ee24 181

Driver for 24xx I2C EEPROMs, 24C01 to 24C512, on the STM32 HAL.

  • I2C
  • EEPROM
  • DMA
lib-installer nimaltd/ee24

seq 65

Non blocking state sequencer and interrupt task queue for STM32, with no RTOS.

  • No RTOS
  • Interrupt safe
lib-installer nimaltd/seq

osal

OS abstraction layer for STM32: the same mutex and delay on bare metal, FreeRTOS and ThreadX.

  • FreeRTOS
  • ThreadX
  • Bare metal
lib-installer nimaltd/osal

littlefs

LittleFS by the littlefs project, a fail-safe file system, ready for lib-installer.

  • File system
  • Power loss safe
lib-installer nimaltd/littlefs
