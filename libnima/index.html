NewlibNIMA 1.1.0: what changed

libNIMA, a library into any project.

Open a project, add a library by its repository, see whether it fits, and install it, from a window or from the libnima command: STM32 with CubeMX, Zephyr and nRF Connect SDK, ESP-IDF, Arduino and PlatformIO. Your settings survive every update, and every project file is saved before it changes. Free and open source, on Windows, macOS and Linux.

Every file, and the notes
02

What it does

  • Five platforms, one fileSTM32 with CMake, STM32CubeIDE, Keil, IAR or CubeMX's Makefile; a Zephyr module, nRF Connect SDK too; an ESP-IDF component; an Arduino library; PlatformIO's lib/. One libnima.yml serves them all.
  • It reads your projectIt says which platform your project is and which file told it, and you can change it.
  • Checked before anything is writtenEach library is marked OK, CHECK or NO against your project, with the way to put it right, and a run that is refused writes nothing.
  • What a library needs comes firstThe libraries it needs go in before it, each at a version that will do, and one already there is kept.
  • Updates keep your settingsWhat you wrote between USER CODE lines survives every update, anything else of yours is saved as a .bak first, and an uninstall gives your files back.
  • Parts you choose, steps it asks aboutOptions are asked about at the first install, and a step a library runs is shown in full and asked about before it runs.
  • A window and a commandThe libnima command is on your PATH and does what the window does, for a script or a build server: --check, --yes, --lint.
  • A libnima.yml written with youNew fills one in from what is in the library's folder, a form beside the text has a place for every key, and each problem comes with a fix.
  • Private repositoriesA GitHub token that can read it, asked for and never saved, or from GITHUB_TOKEN.
  • Without internetFrom the zip of GitHub's Download ZIP, with no need to unpack it, and the zip of each library it needs beside it.
